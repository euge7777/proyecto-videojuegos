# Run Milo, run!
## De qué va nuestro juego? 
### Es un videojuego endless runner de acción y fantasía ambientado en un mundo medieval. El jugador controla a Milo, un personaje que corre constantemenre mientras debe evitar obstáculos, derrotar enemigos y recolestar items para sobrevivir la mayor cantidad de tiempo posible.
